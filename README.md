# ShopEase – Mini E-Commerce Application

A responsive mini shopping website built with HTML, CSS and vanilla JavaScript.

## Features
- Eight products rendered dynamically from a JavaScript array.
- Add products to the shopping cart.
- Increase/decrease quantities and remove items.
- Automatic subtotal, delivery fee and grand total.
- Cart is saved in LocalStorage and restored after page refresh.
- Demo checkout preview (no real payment processing).
- Responsive layout for desktop, tablet and mobile.
- Empty-cart state, toast messages and basic error handling for LocalStorage.

## Run locally
1. Extract the ZIP file.
2. Open the folder in Visual Studio Code.
3. Open `index.html` with the Live Server extension, or open it directly in a browser.
4. Add products and test the cart.

## Delivery rule
Delivery costs ₹99 for orders below ₹2,000. Delivery is free for orders of ₹2,000 or more.

## Technologies
HTML5, CSS3, JavaScript (DOM manipulation and LocalStorage).

## Note
This is an educational demo. Checkout is only a preview; it does not collect personal details or process payments.
